# Contributing to Drift

All contributions are welcome and appreciated! Wether you want to submit a bug report, suggestions or help with active development, everything is welcome!

## Issues or bugs

Found a bug or do you have an idea that could improve Drift? You can submit an issue on our [GitHub Repository](https://github.com/socatlolmeow/drift)! Please check if your problem already has an active issue and **only open issues that are related to Drift.**

## Submitting a PR

Make sure to test the feature or bugfix that you have implemented and show this in the PR.
